# Source material (removed)

This folder originally contained the source paper that was formalized:

> T. F. Bloom, W. Sawin, C. Schildkraut, D. Zhelezov,
> *The sum-product conjecture is false for real numbers*.

During development, the LaTeX sources (`SPArxiv.tex`, `SPCrefs.bib`) and the compiled
`paper.pdf` were extracted into this folder from the arXiv source bundle (top-level
`SPArxiv.tex`, compiled with `pdflatex` / TeX Live 2025).

Those files are not included in this repository. The paper itself is available from arXiv:

> **arXiv:2605.28781** — <https://arxiv.org/abs/2605.28781>

See [`formalization.yaml`](../../formalization.yaml) at the repository root for the source
metadata and the statement-to-declaration alignment.
